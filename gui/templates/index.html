Step 3 · Preprocessing & Quality Control NEW
Already preprocessed your EDF? Skip the optional notch and bandpass filters. IQR amplitude clipping remains on by default, followed by resampling to 128 Hz when needed and robust scaling for model input. You can turn off IQR clipping separately below.

SLEEPYLAND processes EEG and EOG in this order: 1. optional notch filter → 2. optional bandpass filter → 3. IQR amplitude clipping (on by default) → 4. resampling to 128 Hz when needed → 5. robust scaling. EMG starts at step 3: the shared notch and bandpass settings do not apply to EMG. Automatic exclusion of corrupted channels and epochs is not available yet.

1 · Notch filter (optional; EEG and EOG)

Reduce mains interference at 50 or 60 Hz in EEG and EOG. Choose the frequency used where the recording was made. EMG is excluded from this filter.

2 · Bandpass filter (optional; EEG and EOG)

Keep frequencies between the low and high cutoffs in EEG and EOG. The same range applies to both if selected. EMG is excluded: chin and limb EMG are commonly filtered at 10–100 Hz, which needs separate settings and adequate original sampling rate.

3 · IQR amplitude clipping (on by default)

As in the original SLEEPYLAND preprocessing, values beyond 20 times the recording-wide interquartile range (IQR) are clipped before resampling. Turn this off if you do not want another clipping pass. Clipping limits extreme values; it does not exclude corrupted channels or epochs from prediction averaging.

4–5 · Resampling and scaling (always applied when needed)

After clipping, SLEEPYLAND resamples channels whose sample rate differs from 128 Hz, then robust-scales each channel for the models. These steps run for every selected modality.

Planned quality check (QC) Not available yet

A future check would flag corrupted epochs, exclude heavily affected channels, and omit flagged epochs from channel averaging.

Step 5 · Output Folder
This creates one results folder for the run. Each uploaded EDF gets prediction files for every selected model and signal type, plus an ensemble result if selected. Open the folder for a model, then its resolution and signal type, to find the prediction and review-software import files.

What is inside each result file?
*_PRED.npy · probability array
NumPy data with one probability per sleep stage (W, N1, N2, N3, REM) for each epoch. At 30-second resolution it has shape [epochs, 5]. Shorter USleep resolutions can include multiple predictions per epoch.
*_PRED.annot · annotation and probabilities
Tab-separated rows with the predicted stage, channel name, start and stop time, and a meta field containing pN1, pN2, pN3, pR, and pW probabilities. Annotations are written as 30-second rows even when USleep outputs finer predictions, such as one prediction per second.
*_VALID.npy · majority contribution indicator
One Boolean value per epoch in each model's majority/ folder. It is normally all true now; the planned QC could mark epochs false when no acceptable channel contributes.
recording.h5 · detailed HDF5 data
One file per recording at the result root holds selected models under models/, including a combined lead result for each model when multiple leads are available. When selected, ensemble/ holds per-channel, lead majority, and combined soft-voting probabilities.
Software import folder
Contains files formatted for the review software selected in Step 4, generated from the annotation.
